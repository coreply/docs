---
title: "Mistral"
description: "Set up Coreply with Mistral chat-completions models."
---

Use this provider for Mistral's regular chat-completions models. For the separate fill-in-the-middle provider, see [Mistral FIM](/providers/mistral-fim).

<Steps>
  <Step title="Get your API key">
    Go to [console.mistral.ai/api-keys](https://console.mistral.ai/api-keys) and create a new API key.
  </Step>
  <Step title="Choose Mistral in the app">
    Open Coreply and choose **Mistral** under **API Provider**.
  </Step>
  <Step title="Enter your settings">
    Fill in the following values:

    | Field | Value |
    | ----- | ----- |
    | API Key | Your key from Mistral |
    | Model | `mistral-small-latest` |

  </Step>
  <Step title="Choose a model">
    The following models are recommended for Coreply:

    ```text
    mistral-small-latest
    mistral-small-2603
    ```

    You're welcome to try other models from Mistral's catalog.

  </Step>
</Steps>
